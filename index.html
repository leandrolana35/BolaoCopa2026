Configure o Firebase para ativar o modo online

⚠️ O Firebase ainda não está configurado. Siga os passos abaixo e cole sua configuração no arquivo HTML.
1 Crie um projeto no Firebase

Acesse console.firebase.google.com, clique em Adicionar projeto e siga o assistente (pode desativar o Google Analytics).

2 Ative o Firestore Database

No menu lateral: Build → Firestore Database → Criar banco de dados. Escolha Modo de teste (válido por 30 dias — tempo suficiente para a Copa!).

3 Ative o Authentication (e-mail/senha)

No menu lateral: Build → Authentication → Começar → E-mail/Senha → Ativar.

4 Copie a configuração do app

Vá em Configurações do projeto (⚙️) → Geral → Seus apps → Adicionar app → Web (</>). Copie o objeto firebaseConfig.

5 Cole no arquivo HTML

Abra o arquivo bolao-copa-2026-firebase.html em um editor de texto e substitua o bloco abaixo:

const FIREBASE_CONFIG = { apiKey: "", // ← Cole aqui authDomain: "", // ← Cole aqui projectId: "", // ← Cole aqui storageBucket: "", // ← Cole aqui messagingSenderId: "",// ← Cole aqui appId: "" // ← Cole aqui };
6 Hospede no Netlify (grátis)

Acesse netlify.com, crie uma conta e arraste o arquivo HTML para a área de deploy. Pronto — você terá uma URL pública para compartilhar!

💡 Dica: Após configurar, o primeiro usuário que se registrar com o código copa2026admin vira administrador e pode inserir resultados.
